# CIFI Gem Planner

An unofficial, non-commercial community tool for planning CIFI Gem levels,
nodes, upgrade costs, bonuses and orb spending.

Live site: https://deathsunset.github.io/cifi-gem-planner/

The planner stores progression locally in the browser. It does not require an
account, connect to the game or send player data to a server.

## Local development

Prerequisite: Node.js 22 or newer.

```bash
npm install
npm run dev
```

Validation and static GitHub Pages build:

```bash
npm run build
npm run build:pages
```
